
# 🚗 Road Accident Analysis Dashboard

## 📊 Project Overview

This project is an interactive **Road Accident Analysis Dashboard** created using **Power BI**.  
The dashboard provides a clear view of road accidents, casualties, vehicle types, road conditions, locations, and other important factors.

## 🎯 Key Features

- 🚨 Total CY Casualties and Accidents
- 💀 Fatal, Serious & Slight Casualties
- 🚗 Casualties by Vehicle Type
- 📈 Monthly Casualties Trend
- 🏙️ Urban vs Rural Casualties
- 🛣️ Casualties by Road Type
- 💡 Casualties by Light Condition
- 📍 Casualties by Location
- 🌦️ Road Surface & Weather Condition Filters

## 🛠️ Tools & Technologies

- 📊 Power BI
- 🔄 Power Query
- 🧮 DAX
- 🧹 Data Cleaning & Transformation
- 📈 Data Visualization

## 📌 Dashboard Insights

The dashboard helps identify accident patterns and understand how different factors such as **vehicle type, road type, location, light conditions, and urban/rural areas** affect road casualties.
